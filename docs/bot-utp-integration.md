# Контракт скрапер → бот: УТП по сериям

Самодостаточная памятка для сессии/разработчика бота `Splithub_api_telegram_me`
(локальная папка: `Site_ostatki_api_teleram`, ветка `claude/jac-supplier-integration`).

## Что готовит скрапер `ostatki_mdv_b2b`

Три файла в `data/` (на VPS рядом со скрапером; пути отдаются боту через `.env`):

| Файл | Что внутри | env-переменная бота |
|---|---|---|
| `jac_stock_latest.json` | остатки+цены JAC (список товаров: article, path, brand, series, price…) | `JAC_STOCK_JSON` |
| `jac_specs_latest.json` | ТТХ карточек `{артикул: {brand, series, characteristics}}` | `JAC_SPECS_JSON` |
| **`jac_utp_latest.json`** | **УТП по сериям (новое)** | **`JAC_UTP_JSON`** (добавить) |

## Формат `jac_utp_latest.json`

```json
{
  "MDV":              { "INTEGRA PRO": ["матовый корпус", "встроенный ИИ", "3D Air Flow", ...] },
  "THAICON":          { "PHANTOM INVERTER": ["Full DC-Inverter", "4D Air Flow", ...] },
  "Mitsubishi Heavy": { "SRK-ZSX DIAMOND": ["Очень тихие", "Управление через Wi-Fi", ...] }
}
```

- Ключ 1-го уровня — **бренд** (точно как поле `brand` в остатках JAC).
- Ключ 2-го уровня — **серия в нормализованном виде**: UPPER CASE, схлопнутые пробелы.
- Значение — список строк-преимуществ (уже отобран владельцем).

## Как боту достать УТП для товара

```python
def normalize_series(s: str) -> str:
    return " ".join((s or "").upper().split())

utp = utp_data.get(product["brand"], {}).get(normalize_series(product["series"]), [])
# utp — список строк; если пусто, у серии нет УТП (норм) — просто не выводить блок
```

Серия и бренд товара берутся из того же `jac_stock_latest.json` / карточки. Связка
идёт по **имени серии**, артикул/мощность не важны (УТП общие на всю серию).

## Граничные случаи

- **EUROKLIMAT** — УТП нет (на сайте не публикуются). Бренда может не быть в файле — это нормально.
- **MDV** — собран из официального прайс-листа (все серии, включая on/off), имена серий уже под JAC.
- Если серии товара нет в файле — выводим товар без блока УТП, не падаем.

## Важно про деплой и порядок

- Cron на VPS до 09:00 МСК: `scrape` → `specs`; `jac_utp_latest.json` обновляется
  отдельно (вычитка владельцем редкая, серии меняются нечасто).
- В репозитории бота `origin/main` ушёл вперёд параллельной работой (характеристики
  серии, УТП Бриза, кнопка-меню) — пересекается по `menu.py`/`bot.py`/`report.py`.
  УТП-блок JAC встраивать ПОСЛЕ согласования с этим мержем, через PR (не force-push).
- Связки: бот работает в паре со сток-ботом и фото-агентом — менять место вывода УТП
  с учётом их форматов сообщений.
